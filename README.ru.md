Leveler выравнивает громкость любого HTML5-видео и аудио: тихие диалоги становятся громче, взрывы тише, и во время фильма больше не нужно крутить громкость. Ещё он меняет скорость от 0.25× до 4× без изменения высоты голоса. Всё работает локально в браузере.

> **Статус: прототип (шаг 1).** Одна цепочка компрессора, ползунок «Выровнять звук» и скорость. Пресеты, настройки по сайтам, индикаторы уровня, горячие клавиши и сайт появятся на следующих шагах.

## Установка

В магазинах пока нет. Чтобы попробовать прототип:

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
3. Включите **Режим разработчика** (справа вверху).
4. Нажмите **Загрузить распакованное** и выберите папку `extension`.
5. Закрепите Leveler на панели, откройте страницу с видео и запустите его.

Firefox: `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение…** → `manifest.json` из распакованного `dist/leveler-firefox-<версия>.zip` (см. [Сборка](#сборка)). В разрешениях дополнения разрешите доступ ко всем сайтам, иначе content script не запустится.

## Возможности прототипа

- Цепочка Web Audio для каждого `<video>` и `<audio>`: high-pass → эквалайзер на 3 полосы → компрессор → makeup gain → защитный лимитер
- Один ползунок «Выровнять звук» (0–100 %) управляет порогом, степенью сжатия, мягкостью и атакой компрессора
- Вкл/выкл без перезагрузки страницы: плавный переход между обработанным и оригинальным звуком
- Параметры меняются плавно (`setTargetAtTime`), без щелчков
- AudioContext запускается только после действия пользователя на странице, поэтому видео не остаётся без звука, пока его ждёт
- Видео, которые появляются позже (MutationObserver и перехват `play`), iframe (`all_frames`), полноэкранный режим
- Одна цепочка на элемент (WeakMap), повторно не подключается
- Скорость 0.25–4× с `preservesPitch` и коротким оверлеем на видео
- DRM и источники с другого домена распознаются и не трогаются, в popup сообщение «Этот сайт не поддерживает обработку звука»
- Светлая и тёмная тема по системной настройке, English / Русский / Українська

## Как работает откат для DRM и CORS

Для DRM-видео и для файлов с другого домена без CORS браузер отдаёт в Web Audio только тишину. Подключённый к Web Audio элемент нельзя отключить до перезагрузки страницы, поэтому Leveler проверяет заранее:

- задан `video.mediaKeys` или пришло событие `encrypted` → DRM, не подключаем;
- файл на другом домене, а у элемента нет атрибута `crossorigin` → не подключаем;
- известные сайты только с DRM (Netflix, Disney+, Prime Video, Max, Hulu и другие) не подключаются никогда.

Если тишина всё же пришла после подключения (например, адрес на своём домене перенаправляет на чужой), анализатор на входе видит ровные цифровые нули 5 секунд воспроизведения, хотя браузер декодирует звук. Тогда Leveler переключается на оригинальный путь, запоминает сайт в `chrome.storage.local`, а popup просит перезагрузить страницу. После перезагрузки на этом сайте играет оригинальный звук; кнопка «Попробовать снова на этом сайте» в popup его забывает.

## Результаты проверки

Облачная среда, в которой собран прототип, не имеет доступа к YouTube, Twitch и Netflix, поэтому **на реальных сайтах прототип ещё не проверен**. Ниже честно указано, что проверено.

| Где | Результат |
|---|---|
| Локальная тестовая страница, Chrome for Testing 153, headless (`store/tests/run.js`) | ✅ все проверки прошли, подробности ниже |
| YouTube | ⏳ ещё не проверено |
| Twitch | ⏳ ещё не проверено |
| Сторонний плеер (Video.js / JW Player на новостном сайте) | ⏳ ещё не проверено |
| Netflix | ⏳ ещё не проверено (ожидается: распознаётся как DRM, оригинальный звук, сообщение в popup) |
| Firefox | ⏳ ещё не проверено (скрипт сборки делает zip для Firefox) |

Автотест играет сгенерированный 12-секундный тон, где чередуются −36 dBFS («диалог») и −3 dBFS («взрыв»), и проверяет:

- цепочка подключается только после клика и `play`;
- на 50 % разница между тихим и громким сжимается с 33 dB примерно до 11 dB, на 100 % примерно до 3 dB; громкое остаётся заметно ниже 0 dBFS;
- выключение пропускает оригинальный звук и глушит обработанный путь, включение возвращает обработку, всё без перезагрузки;
- видео, добавленное на страницу позже, подключается; повторный запуск того же элемента не подключает его второй раз; `<audio>` во iframe тоже подключается;
- скорость 1.5× применяется во всех фреймах с `preservesPitch`, появляется оверлей, скорость ограничена 4×;
- файл с другого домена без CORS не подключается;
- адрес на своём домене с перенаправлением на чужой распознаётся как тишина, сайт запоминается и после перезагрузки не трогается.

Автотест не покрывает: автозапуск совсем без действий пользователя (headless-браузер сразу разрешил AudioContext) и настоящий DRM.

Запустить самому: `npm i playwright`, затем `node store/tests/run.js [папка-для-скриншотов]`.

## Сборка

```
python3 tools/build.py
```

Создаёт `dist/leveler-chrome-<версия>.zip` и `dist/leveler-firefox-<версия>.zip`, версия берётся из `extension/manifest.json`. Перед упаковкой скрипт проверяет файлы из манифеста, одинаковые ключи во всех `_locales` и синтаксис JS (если установлен `node`).

## Конфиденциальность

Leveler не собирает данные и ничего никуда не отправляет: звук обрабатывается на вашем устройстве. Настройки хранятся в браузере (`chrome.storage`).
